# Comparafar

- **Objetivo:** Plataforma modular de comparación económica de tratamientos en farmacia hospitalaria. Primer módulo: mieloma múltiple.
- **Área funcional:** Gestión económica
- **URL de acceso:** Pendiente de publicar (el portal enlaza al repositorio)
- **Código:** https://github.com/ramonmorillo/comparafar
- **Incorporación al portal:** Noviembre 2026
- **Estado:** Prototipo. Datos de pacientes ficticios; pautas y precios pendientes de validación. Las comparaciones son económicas y no implican superioridad terapéutica ni recomendación clínica.
- **Observaciones:** Aplicación independiente. Cuando exista una URL pública de la aplicación, sustituir el `href` de la tarjeta en `index.html` y esta ficha.
